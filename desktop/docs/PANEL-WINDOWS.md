# 独立面板窗口

侧栏里的面板都可以拆成独立窗口：字幕、总结、对话，以及任意插件面板。

## 怎么用

- 悬停侧栏导航项，点右侧的 `⧉`；
- 或右键导航项 → 「在独立窗口打开」；
- 独立窗口的标题栏可以拖动；右上角三个按钮分别是「置顶 / 合回主窗口 / 关闭」。

## 行为

| 项 | 说明 |
|---|---|
| 单实例 | 同一面板只会有一个独立窗口，再次打开只是聚焦 |
| 位置与尺寸 | 写进 `<userData>/panel-windows.json`，重启按原样恢复 |
| 上限 | 最多同时 12 个 |
| 置顶 | 每个窗口单独记住 |
| 关闭主窗口 | 独立窗口保留；从托盘退出时一起关闭 |
| 主窗口内的面板 | 拆出不会从侧栏移除；点「合回主窗口」只是关掉独立窗口 |

## 实现边界

独立窗口复用同一个 renderer 包（`?window=panel&section=…`），自己重新取标签页与设置，
不共享主窗口的 React 状态。面板组件（`SubtitlesPanel` / `SummaryPanel` / `ChatPanel` /
`PluginPanel`）本身不改，因此面板后续迭代会自动同步。

已支持：字幕、总结、对话、插件面板、设置页、工作台（库）。

暂不支持：起始页、地址栏/标签栏这类壳层控件（它们依赖主窗口的布局与交互状态）。
