### 字幕
- **获取提速**：页面桥改为**先请求 WBI 签名接口**，成功就直接返回，不再依次请求无签名 `player/v2`、播放器实例、`__INITIAL_STATE__`；签名接口明确返回空时也直接结束，不再 6 次轮询。
- **转录/翻译结果刷新后保留**：ASR 与翻译结果按「视频 + 字幕轨」缓存在内存中；刷新/重新获取时自动恢复（翻译同时恢复双语视图），并保留「语音转录」轨可切换。编辑、优化、清空或重新转录会使对应翻译缓存失效。
- **转录结果不再被刷新清掉**：ASR 结果缓存在内存中，刷新/重新获取时如果本视频没有官方轨，会自动恢复转录字幕，并保留「语音转录」轨可切换。
- **关键修复：字幕只信 WBI 签名接口**。无签名的 `/x/player/v2` 在风控降级时会返回**别的视频的字幕**（社区已确认），现在只要 `/x/player/wbi/v2` 请求成功，就完全以它的结果为准，哪怕返回 0 条；无签名结果、播放器实例、`__INITIAL_STATE__` 和网络嗅探只在签名接口失败时兜底。
- **修复「没有字幕却抓到别的视频字幕」**：签名接口返回空时页面桥直接返回 0 轨；配合下面的时长/覆盖率/内容校验，最终显示“没有可用字幕”，不再串片。
- 非全片覆盖（<97%）的字幕再做 **标题/简介关键词校验**：内容完全对不上标题的轨直接拒绝，避免「郎酒视频配京都旅行字幕」。

- 播放器实际时长与页面信息不一致时先等待（避免 SPA 切页时拿到上一个视频的预取轨）；被拒轨自动重新获取最多 4 次，仍不匹配则明确报错，不显示错误字幕。

- **修复字幕串视频**：自动选轨优先「结束时间与视频时长对齐」的轨；末句超出片尾 8%（且 >8s）的轨判为别的视频/整段合集，直接丢弃并置灰，不再按行数最多选中错误轨。
- **翻译视图真正生效**：翻译完成后可在「原文 / 译文 / 双语」之间切换，行内同时显示译文；复制全部与单行复制都遵循当前视图。

- **清空字幕**按钮：只清当前显示，不删除本地库与缓存；清空后可重新获取。
- **字幕诊断补全**：逐来源错误（来源 / code / message）、被排除的外来轨明细、候选轨判定（可用行数 / 下载失败 / 时长超出 / 覆盖不足）、身份不一致与采集期间切换提示。
