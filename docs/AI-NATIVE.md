# AI 原生浏览：路线图（0.166 起）

> 目标：让 AI 从「几个按钮」变成「一层的操作方式」，同时把浏览器基础能力补到接近成熟产品。
> 这份文档定方向、分阶段、给验收；具体落地以 CHANGELOG / HANDOFF 为准。
>
> **状态（0.166.0）**：Phase 1 已落地（AI 动作注册表、命令面板问 AI、阅读清单 + AI 摘要入口）；Phase 2–4 待做。

## 1. 判断：现在的问题

- AI 是**点状**的：总结在侧栏、对话在侧栏、划词在页面、阅读模式又一个入口；用户要记「哪个功能在哪」。
- 动作**不可组合**：选中文字只能解释/翻译/总结，不能「解释并存入知识库」「对比两个标签页」。
- 浏览器基础仍有差距：没有阅读清单、没有整页翻译、没有 PDF 阅读、没有密码管理/自动填充。
- AI 不知道**你在看什么**：除了对话面板的「当前页面」开关，其它动作都要用户重新描述上下文。

## 2. 方向：三层 AI

```
L3 主动层   页面摘要卡 / 归档建议 / 标签分组建议 / 阅读清单 AI 摘要
L2 对话层   全局 Ask（任意位置 Ctrl+Shift+K）/ 就地回答卡片 / 追问
L1 动作层   统一 AI 动作注册表（选中/页面/链接/标签/书签/历史）→ 划词条、右键、命令面板、列表行
```

原则：
1. **一个动作只定义一次**（`shared/aiActions.ts`），所有入口从注册表渲染；
2. **上下文自动带上**（当前页面/选中文本/标签/URL），用户只写问题；
3. **结果可去向**（复制 / 进对话 / 存笔记 / 进知识库），不做只能看的弹窗。

## 3. 与成熟浏览器的差距（优先级）

| 能力 | 现状 | 优先级 | 计划 |
|---|---|---|---|
| 阅读清单 | 无 | P0 | 本次：保存/列表/已读/移除 + AI 摘要入口 |
| 整页翻译 | 只有划词/字幕翻译 | P0 | Phase 2：按块翻译 + 原文/译文切换 |
| 全局 AI 提问 | 只有侧栏对话 | P0 | 本次：命令面板问 AI；Phase 2：独立浮层 |
| 标签页搜索/分组 | 有 | — | 保持 |
| 下载/历史/书签管理 | 有 | — | 保持 |
| PDF 阅读 | 无 | P1 | Phase 3 |
| 密码管理/自动填充 | 无 | P2 | 长期（需安全模型） |
| 账号同步 | 无 | P2 | 长期 |

## 4. 阶段

### Phase 1（本次，0.166.0）

- `shared/aiActions.ts`：AI 动作注册表（scope + prompt 模板）；
- 命令面板「问 AI」：任意输入 → 带当前页面上下文进对话；静态 AI 快捷动作（总结本页/解释选中/翻译选中）；
- 阅读清单：`reading_list` 表 + IPC + 浏览器中心「阅读」分区 + 地址栏「添加到阅读清单」；
- 阅读清单条目「AI 摘要」：带 URL 进对话，让模型自己读；
- 验收：动作从注册表渲染、命令面板可问 AI、清单可增删改查。

### Phase 2

- 全局 Ask 浮层（Ctrl+Shift+K）：流式回答 + 追问 + 复制/进对话；
- 整页翻译：按块翻译，原文/译文切换，失败回退；
- 划词结果就地卡片（不跳侧栏）。

### Phase 3

- 主动建议：书签归档建议、标签分组建议、历史主题聚类（都需确认后执行）；
- PDF 阅读 + AI 摘要；
- 阅读清单自动摘要（保存时后台生成）。

### Phase 4

- 记忆层：页面/对话/笔记统一进知识库，跨页引用；
- 浏览器基础：自动填充（本地加密）、更多站点兼容。

- [x] 阅读条目可一键「AI 摘要」；
