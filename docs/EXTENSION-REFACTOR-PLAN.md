# 插件重构计划：与桌面端共用新流程

> 状态：进行中（第一刀：选轨规则已完成）
> 目标版本：桌面 0.162.0 / 插件 2.20.0（暂定）
> 背景：EXTENSION-DESKTOP-ALIGNMENT.md 完成的是“在线委托 + 核心库互通”；本文件描述下一阶段：
> 插件自己运行桌面端的新流程，桌面在线时再借用桌面资源增强。

## 1. 已确认的产品决策

| 项 | 决策 |
|---|---|
| 插件独立运行 | 使用与桌面端同一套新流程 |
| 桌面在线 | 默认“自动优先桌面”；失败回退插件本地新流程 |
| 设置权威 | 首次连接用户选择主端；之后主端权威、可切换 |
| 迁移范围 | 设置 + 插件历史库 + 对话，双向 |
| API Key | 默认迁移；迁移前明确提示明文风险；提供“不同步 Key”勾选项，默认不勾选 |
| 插件 UI | 改成桌面端 5 入口：字幕 / 总结 / 对话 / 库 / 设置 |
| 字幕选轨 | 见第 3 节（已实现） |

## 2. 目标架构：一套流程，两个宿主

唯一源码放在 desktop/src/shared/core/：

- prompts/：总结、对话、翻译、校对、格式规则
- summary/：新总结链路（官方分段 + 工具循环，无校对/分段）
- chat/：系统提示词、上下文压缩、工具策略
- subtitles/：选轨、身份校验
- export/：6×4
- settings/：共享 schema、默认值、迁移

桌面端直接 import TS；插件端由构建脚本打成 shizi-extension/src/shared/core.bundle.js（ESM）。

插件内部增加 flow 层：

- flow.summarize(input)
- host = auto ? (desktop ready ? desktop : plugin) : ...
- DesktopHost：/v1/rpc，同一套参数
- PluginHost：本地 core

“借用桌面流程”不是另一套逻辑，而是同一套 core 在桌面进程执行，换取：

- 桌面 Key / 模型 / 用量；
- 本地 Whisper、TTS；
- 本地 stdio MCP；
- 文件/OCR/库上下文。

## 3. 字幕选轨（已完成第一刀）

### 3.1 删除

- 桌面：末句 1.08×片长+8s、覆盖率 70%/50%、覆盖率 <97% 关键词判定、
  coverageRetryRef、aligned/行数排序。
- 插件：overrun 15%/12s、覆盖率 18/22/25%、wrongPart 重试、行数排序。

### 3.2 保留

- WBI 签名结果优先；
- 身份校验：expectSignature、cid 自身一致、正文里的其他 BV/cid；
- WBI 成功返回 0 轨 = 无字幕，不回退；
- WBI 失败才回退，回退轨必须通过身份校验；
- 时长/覆盖率/行数只做展示，不参与拒绝或排序。

### 3.3 选轨顺序

1. 来源：WBI > 播放器 > 初始状态/嗅探；
2. 语言：手动记忆 > 当前/中文（zh-CN/zh-Hans）> 其他中文 > ai-zh > 其他；
3. 同语言：人工轨 > AI 轨；
4. 仍并列：保留平台返回顺序；
5. 默认第一条，其他轨可在切换列表选择。

### 3.4 手动记忆

- 按 bvid + cid + 分P；
- 只存 lan + source + isAi，不存签名 URL；
- 轨不存在时回退默认规则；
- 先按端本地保存，不纳入设置同步。

## 4. 设置

共享字段：AI（平台/Key/模型/任务槽位/温度/长度/档案）、检索、ASR、提示词/格式规则/术语表、
导出默认值、可映射的 Skills/MCP。

不共享：插件的内嵌面板/播放器按钮/画面字幕/布局；桌面的浏览器/起始页/桌宠/窗口/数据目录。

首次连接弹窗：

- 以桌面端为准；
- 以插件端为准；
- 预览数量与 Key 是否包含；
- 两端备份、可撤销；
- 记录主端，可切换。

## 5. 数据

- 插件历史库 → 桌面 library.db：批量、幂等；
- 桌面库 → 插件镜像：已有，支持首次全量 + 增量；
- 对话：双向；插件“对话”页增加会话列表，承接桌面对话；
- 任务/用量：后续评估。

## 6. 插件 UI

五个入口：

1. 字幕：保留现有能力；
2. 总结：新流程、官方分段、无校对/分段；
3. 对话：会话列表 + 对话；
4. 库：桌面镜像/回写，保留；
5. 设置：按共享 schema 重组分组。

## 8. 验收

- 同一视频、同一模型：插件独立运行与桌面总结使用同一提示词/分段策略；
- 桌面在线时自动用桌面执行，失败回退本地不丢结果；
- 两端设置字段一一映射，切换主端后保留 Key/模型/提示词；
- 选轨不再因时长/覆盖率/行数拒绝合法字幕；
- 插件 5 入口可用；
- 桌面 npm run check / npm run smoke、插件全量测试通过。
