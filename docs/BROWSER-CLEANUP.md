# 浏览器旧逻辑清理（0.165.1）

> 背景：浏览器功能经过多轮迭代，早期交互模型留下的入口/开关/路径还留在代码里，
> 与现在的「起始页 + 书签 + 浏览器中心」模型冲突，用起来别扭。
> 本文档是这次清理的完整清单与验收标准。

## 1. 现行模型（判断标准）

1. **新标签页 = 起始页**：Ctrl+T、命令面板、标签栏 + 都打开同一起始页；不再直接开 B 站。
2. **书签是唯一收藏**：星标 → 收藏弹窗（改名/文件夹）；起始页快捷方式是独立入口，文案要说清。
3. **设置只有一处**：同一行为不能在两个分组里各有一个开关。
4. **菜单只有一套**：不再保留「主进程不可用时的 HTML 菜单」这种死路径。
5. **命名一致**：主页按钮、起始页、历史、书签、下载在菜单/设置/提示里同词同义。

## 2. 审计发现与处理

| # | 残留 | 问题 | 处理 |
|---|---|---|---|
| 1 | Ctrl+T / 命令面板「新建标签页」 | 走 `newTab()` 直接开 B 站，和标签栏 +（起始页）不一致 | 统一打开起始页 |
