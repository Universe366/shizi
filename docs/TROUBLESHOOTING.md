# 故障排查

> 适用：桌面 0.162.25 / 插件 2.20.14
> 先判断问题在哪一层：桌面启动、插件加载、桥连接、字幕抓取、AI/ASR 服务、更新。

## 1. 先收集信息

- 桌面：设置 → 高级与诊断 → 诊断，复制构建指纹与桥状态；
- 插件：设置 → 高级与诊断，复制构建指纹；侧边栏顶部状态点显示桥连接；
- 记录：版本号、Windows 版本、Chrome/Edge 版本、复现步骤、报错原文；
- 不要发 API Key、Bridge Token、Cookie 或带登录态的页面 HTML。

## 2. 桌面端打不开 / 启动即退

### 现象：命令行报 bad option，或 Electron 以 Node 模式运行

本机可能设置了 ELECTRON_RUN_AS_NODE=1。启动前清掉：

    unset ELECTRON_RUN_AS_NODE

PowerShell：

    Remove-Item Env:ELECTRON_RUN_AS_NODE

### 现象：打包/更新时报 EBUSY 或 app.asar 被占用

先退出正在运行的「拾字」和 release/win-unpacked/拾字.exe，再重新打包或安装。

### 现象：绿色版双击没反应

确认解压完整；不要直接在 zip 里运行。安装包未签名，SmartScreen 提示属于已知状态。

## 3. 插件加载失败

- Chrome/Edge 打开扩展管理页，开启开发者模式；
- 选择解压后的 shizi-extension 目录，不要选外层 zip；
- 修改后台代码后，必须在扩展管理页点刷新；只刷新页面不够；
- 修改 content script 后，还要刷新 B 站页面；
- 若提示清单错误，检查 manifest.json 是否完整、是否误改了版本号。

## 4. 插件连不上桌面

按顺序检查：

1. 桌面端「设置 → 桌面与数据同步」里桥已启用；
2. 桌面端正在运行，端口未被其它程序占用；
3. 插件与桌面在同一台电脑；
4. 插件设置 → 桌面端 → 重新发现/保存并测试；
5. 防火墙没有拦截 127.0.0.1 本地回环；
6. 桌面端 Token 变化后，插件重新配对。

桥只监听本机回环地址；不要把端口暴露到公网。

## 5. 字幕抓不到 / 抓到别的视频

- 先确认视频页已登录（部分字幕需要登录）；
- 优先让视频播放几秒，再点「获取字幕」，让播放器自己加载轨道；
- 插件按 WBI 签名 + 身份校验选轨；身份不符时会拒绝，不再用时长/覆盖率硬拒；
- 如果 WBI 失败，才回退播放器/初始状态/嗅探；
- 仍然为空：用「语音转录」；
- 具体视频/分 P 有差异时，记录 BV 号、分 P、页面侧/接口侧候选轨，提交诊断信息。

## 6. 总结不联网 / 没有参考网址

- 检查设置 → 检索与扩展：当前检索平台是否有 Key，或「免费引擎兜底」是否开启；
- 总结工具栏的「联网」是否勾选；
- 桌面端总结需要在桌面设置里启用检索；插件连接桌面时使用桌面的联网配置；
- 本地总结会收集 web_search 结果作为参考网址；桌面总结使用桌面返回的 references；
- 若模型平台不支持函数调用，联网工具循环会降级为普通总结，不会报“联网成功”。

## 7. 语音识别误报未配置 Key

- 桌面端已配置本地 Whisper 时，插件会隐藏“语音识别未配置 Key”；
- 仍提示时：先连接桌面，再打开插件；设置 → 桌面与数据同步 → 「只同步 Key」或「以桌面端为准」；
- 只装插件、不用桌面时，仍需要在插件里配置在线 ASR 平台。

## 8. 更新失败

- 桌面自动更新读取 latest.yml；确认 /releases/latest 指向当前版本；
- 更新后仍显示旧版本：完全退出应用再启动，不要只关窗口到托盘；
- 安装包未签名，SmartScreen 需要手动允许；
- 不要手动修改 latest.yml 或替换 release 资产。

## 9. 数据与备份

- 桌面数据库：library.db、chat.db、usage.db，位于设置的数据目录；
- 设置 → 数据与关于 → 备份/恢复；恢复前先退出应用；
- 卸载默认保留数据；迁移目录前先备份；
- 插件数据在 chrome.storage.local 与 IndexedDB；覆盖安装扩展目录通常保留，换扩展 ID 会读不到旧数据，先导出备份。

## 10. 发布 CI 失败

- 先看失败步骤：npm ci、typecheck、test、pack、release；
- npm ci 失败优先检查 package-lock.json 是否与 package.json 同步；
- 发布由 tag 触发，不要在本地直接 publish；
- tag 用桌面版本号（如 v0.162.25），发布后确认 latest.yml 与 Release 资产；
- 0.162.18 曾因 image:generate 未登记 IPC 契约导致测试失败，0.162.19 补齐后重新发布成功，可作为先例。

## 11. 提交问题的最小信息

- 桌面/插件版本；
- 问题发生在“仅插件 / 仅桌面 / 两者连接”哪种模式；
- 复现步骤；
- 诊断文本（已脱敏）；
- 具体视频 BV 号与分 P（字幕问题）；
- 报错截图（不要包含 Key/Token）。
