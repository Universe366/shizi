# 设置页信息架构 v5（0.172.0）

## 1. 结构：4 组 / 9 页

| 分组 | 页面 |
|---|---|
| 基础 | 通用、外观、快捷键、浏览器 |
| AI | AI 与模型、语音与字幕 |
| 工具 | 桌面助手、扩展与自动化 |
| 数据 | 数据与关于 |

## 2. 这一轮把配置搬回了功能现场

| 配置 | 原来 | 现在 |
|---|---|---|
| 字幕显示/翻译/倍速/成片 | 设置 → 语音与字幕 | 字幕面板右上角「字幕与播放设置」弹窗 |
| 视频下载默认值 | 设置 → 下载与导出 | 下载弹窗里本来就有，删除设置里的重复项 |
| 导出默认值 | 设置 → 下载与导出 | 删除（导出时会记住上次选择） |

## 3. 删除了什么

- `DownloadSection`、`ExportDefaultsSection` 两个组件与对应设置页（下载弹窗已有同样的选项）；
- 设置页从 10 页降到 **9 页**，四个导航分组不变；
- 全站唯一的「高级」分组在此前版本已删除，本轮不再引入任何隐藏区。
