# 设置页信息架构 v2（0.169.0）

> v1 把专业项收进「高级与维护」抽屉，虽然短了，但用户看不到有什么、也猜不到在哪，直观性差。
> v2 改成：**每一项都是带图标、标题、一句话说明的卡片**——折叠但可见，重要项默认展开。

## 1. 结构（7 组）

| 分组 | 卡片 |
|---|---|
| 通用 | 启动与主页、默认浏览器、网络代理、窗口与标签、快捷键、视频下载 |
| 外观与浏览器 | 外观、浏览器工具栏、地址栏与搜索引擎、网页与阅读、站点例外与清理 |
| AI 与模型 | AI 平台、对话设置、总结提示词模板、AI 助手、图片生成、对话快捷指令 |
| 语音与字幕 | 语音识别、字幕显示、播放速度、字幕与翻译、校对与术语表、视频成片、导出默认、文字朗读、语音输入、文字识别、本地识别模型 |
| 检索与扩展 | 联网检索、MCP 服务、技能（Skills）、应用插件、浏览器扩展、浏览器插件连接、本地接口（Agent） |
| 桌面助手 | 桌面助手、全局取词、快捷轮盘 |
| 数据与关于 | 数据与备份、版本更新、用量统计、诊断与版本、站点权限 |

## 2. 做了什么

### 删 / 合并

- 删除「效率工具」：悬浮球/桌宠开关与桌面助手重复；
- 「下载完成通知」并入「启动与主页」；
- 「站点缩放」+「站点深色例外」合并为「站点例外与清理」；
- 删除「浏览器插件连接」里的端口与 Token 手动输入（扩展自动发现，手动配置只会吓退用户）；
- 取消「高级与维护」抽屉。

### 视觉

- 卡片：白底、12px 圆角、1px 边框、轻阴影；展开时阴影加强、出现分隔线；
- 标题行：32px 图标块 + 14px 粗标题 + 12px 说明 + 旋转箭头；
- 左侧导航：选中项抬升至白底 + accent 描边，图标随选中变色；
- 页头：18px 标题 + 说明，留出更大呼吸感。
