# 设置页信息架构（0.168.0）

> 问题：设置页有 8 个分组、45 个分区，常用项和一次性维护项混在一起，用户第一眼要被大量开关淹没。
> 目标：**常用项 ≤3 个分区**，其余收进「高级与维护」；合并重复；删掉真正多余的。

## 1. 审计

| 项 | 改造前 | 改造后 |
|---|---|---|
| 分组 | 8（通用 / 外观 / AI / 语音识别 / 字幕播放 / 检索扩展 / 桌面助手 / 数据关于） | **7**（语音识别 + 字幕播放合并为「语音与字幕」） |
| 分区 | 45 | 常用直接露出，其余进抽屉 |
| 重复 | 「效率工具」与桌宠/悬浮球设置重复 | 删除，开关并入「桌面助手」 |
| 碎片 | 「下载」只有一个开关；站点缩放 / 站点深色两个维护列表 | 并入「启动与主页」；合并为「站点例外与清理」 |

## 2. 规则

1. 每个分组默认只露 **≤3 个常用分区**；
2. 专业参数、一次性维护、开发者向功能放「高级与维护」抽屉，默认收起；
3. 同一行为只保留一个入口；
4. 抽屉里的分区仍可被目录搜索到，跳转时自动展开抽屉；
5. 删除控件时保留设置字段（兼容旧配置），只删 UI。

## 3. 分组映射

| 分组 | 常用（直接露出） | 高级与维护（抽屉） |
|---|---|---|
| 通用 | 启动与主页、默认浏览器、网络代理 | 标签页与会话、快捷键、视频下载 |
| 外观与浏览器 | 外观、地址栏与搜索、页面与阅读 | 面板布局 |
| AI 与模型 | AI 平台、对话上下文、总结提示词模板 | 图片生成、对话快捷指令、助手档案 |
| 语音与字幕 | 语音识别、字幕行为、播放速度、字幕与翻译 | 本地模型、朗读、语音输入、OCR、校对术语、导出默认、成片样式 |
| 检索与扩展 | 联网检索 | MCP、Skills、插件、浏览器扩展、插件桥、Agent |
| 桌面助手 | 桌面助手（悬浮球 / 桌宠 / 配色 / 大小） | 快捷取词、快捷轮盘 |
| 数据与关于 | 数据与备份、版本更新 | 用量统计、诊断、站点权限 |

## 4. 验收

- [x] 分组 8 → 7；
- [x] 每个分组首屏分区数 ≤5（外观组实测：5 个常用 + 1 个抽屉，抽屉内 19 个控件默认不可见）；
- [x] 删除重复的「效率工具」；合并下载 / 站点维护；
- [x] 目录跳转能展开高级抽屉；
- [x] `npm run check` / `npm run smoke` 通过。
