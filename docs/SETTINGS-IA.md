# 设置页信息架构 v4（0.171.0）

> 参考对象：Cherry Studio 的设置页——左侧**分组导航**，每个导航项是一个**只放一件事**的页面，
> 右侧是**平铺的行**，没有卡片套卡片，也没有「高级」这种垃圾桶。
> 之前 v2/v3 的问题是：把东西藏进抽屉或「高级」组，用户看不到也不理解，属于掩耳盗铃。

## 1. 导航（4 组 / 10 页）

| 分组 | 页面 |
|---|---|
| 基础 | 通用、外观、快捷键、浏览器 |
| AI | AI 与模型、语音与字幕 |
| 工具 | 桌面助手、扩展与自动化、下载与导出 |
| 数据 | 数据与关于 |

每个页面只承载一个主题：

- 通用：启动与主页、默认浏览器、网络代理、窗口与标签；
- 外观：主题/密度/字号、浏览器工具栏；
- 快捷键：一张可搜索的快捷键表；
- 浏览器：地址栏与搜索引擎、网页与阅读；
- AI 与模型：AI 平台、对话设置、提示词模板、AI 助手、图片生成、对话快捷指令、联网检索；
- 语音与字幕：语音识别、字幕与播放、校对与术语表、本地识别模型、朗读、语音输入、OCR；
- 桌面助手：桌宠/悬浮球、全局取词、快捷轮盘；
- 扩展与自动化：MCP、技能、应用插件、浏览器扩展、插件连接、本地接口；
- 下载与导出：视频下载默认值、导出默认；
- 数据与关于：备份、更新、用量、诊断、站点权限。

## 2. 视觉（对齐 Cherry Studio 的节奏）

- 左侧导航：分组小标题（基础 / AI / 工具 / 数据）+ 图标 + 单行标签，选中项 accent 描边；
- 右侧内容：**平铺行**——分区之间用 1px 细线分隔，没有卡片边框/阴影/圆角；
- 分区标题：24px 图标 + 标题 + 一句话说明 + 展开箭头；展开后内容缩进 26px；
- 页面宽度 980px，左右留白；页头 18px 标题 + 说明。

## 3. 与之前几版的区别

| 版本 | 做法 | 问题 |
|---|---|---|
| v1 | 47 个分区一页铺开 | 太长、没有层次 |
| v2 | 每组一个「高级与维护」抽屉 | 藏起来，用户找不到 |
| v3 | 独立「高级」组 | 掩耳盗铃，主设置仍然一堆 |
| **v4** | 分组导航 + 一页一件事 + 平铺行 | 每页浅、看得懂；没有隐藏区 |
