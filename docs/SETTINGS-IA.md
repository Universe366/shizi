# 设置页信息架构 v3（0.170.0）

> 目标是「打开设置就知道去哪」：主设置 6 组、19 张卡；专业项收进独立「高级」组。
> 与 v2 的区别：不再把专业项塞进每组抽屉，而是所有低频项统一放一个明确的「高级」分组。

## 1. 主设置（6 组 / 19 张卡）

| 分组 | 卡片 | 数量 |
|---|---|---|
| 通用 | 启动与主页、默认浏览器、网络代理、窗口与标签 | 4 |
| 外观 | 外观、浏览器工具栏、地址栏与搜索引擎、网页与阅读 | 4 |
| AI 与模型 | AI 平台、对话设置、总结提示词模板、联网检索 | 4 |
| 语音与字幕 | 语音识别、字幕与播放（内含 4 个子分组）、校对与术语表 | 3 |
| 桌面助手 | 桌面助手（内含 4 个子分组）、全局取词 | 2 |
| 数据与关于 | 数据与备份、版本更新 | 2 |

## 2. 高级（1 组 / 20 张卡）

快捷键、视频下载、本地识别模型、本地接口（Agent）、文字朗读、语音输入、文字识别（OCR）、导出默认、图片生成、对话快捷指令、AI 助手、MCP、技能、应用插件、浏览器扩展、浏览器插件连接、用量统计、站点权限、诊断与版本、快捷轮盘。

## 3. 这次删/并了什么

| 动作 | 内容 |
|---|---|
| 删除 | 面板布局（顺序/显隐，拖拽即可）、站点例外与清理（按站点记忆，属于维护项） |
| 合并分组 | 「检索与扩展」并入「AI 与模型」（联网检索本来就在服务 AI） |
| 合并卡片 | 字幕显示 + 播放速度 + 字幕与翻译 + 视频成片 → 「字幕与播放」一张卡 |
| 合并卡片 | 桌面助手 + 桌宠交互 + 声音与状态 + 桌宠位置 → 「桌面助手」一张卡 |
| 迁移 | 快捷键、视频下载、本地模型、朗读、语音输入、OCR、导出、图片生成、快捷指令、助手、MCP、技能、插件、扩展、桥、Agent、用量、站点权限、诊断、轮盘 → 高级 |
