# 浏览器能力路线图（0.174.0 起）

> 对照 Chrome / Edge / Arc 的能力清单，按「每天会碰到 → 成熟浏览器有 → 我们的差异化」排序。
> 已完成的写入 CHANGELOG，这里只记**还没做**的和为什么。

## 已完成（0.174.0）

- 标签搜索：命令面板（Ctrl+Shift+P / Ctrl+Shift+A）输入即可切换已打开的标签；
- 跟踪器拦截：「网页与阅读」开关 + 主进程 webRequest 拦截常见统计域名（默认关闭）；
- 整页翻译：AI 动作新增「翻译整个页面」，命令面板与 AI 入口可直接调用；
- 跨标签 AI：命令面板「AI：总结打开的标签页」，把全部标签按主题分组并指出可关闭的；
- 标签自动整理：「按网站整理标签页」按域名建组并归位；
- 标签去重：「关闭重复标签页」按 URL 保留第一个；
- 既有能力复核：地址栏建议（历史 + 书签 + 搜索）、标签静音、下载暂停/继续/取消、页内查找、打印/PDF、阅读模式、站点权限均已存在。

## 已完成（0.176.0）
- 网页右键菜单：编辑区剪切/复制/粘贴/全选与拼写建议；链接在系统浏览器打开、下载、复制文字；图片复制/另存；页面翻译、阅读模式、加书签、加入阅读列表、复制标题+链接、打印。

## 待做（按优先级）

### P0

| 项 | 为什么还没做 | 建议实现 |
|---|---|---|
| 跟踪器每站点例外 | 目前只有全局开关，误伤时只能整体关掉 | 在站点信息菜单里加「本站放行」，存 `trackerAllowlist` |
| 崩溃恢复提示 | 已有 sessionRestore，缺「异常退出」标记 | 启动时比对退出标记，给一条「恢复上次 N 个标签」气泡 |
| 整页截图 | `capturePage` 只截视口 | 滚动拼接或 `webContents.printToPDF` 之外的 full-page 方案 |

### P1

| 项 | 为什么还没做 |
|---|---|
| 拆分视图 | 需要主进程同时铺两张 `WebContentsView` 并重排布局，属于架构改动 |
| 标签自动整理 | group API 已有，缺「按域名/主题自动分组」规则与撤销 |
| 历史/书签语义检索 | 需要本地嵌入或 AI 检索层，当前只有关键词 |
| 下载限速/重试 | 暂停/继续已接；限速需要改造 yt-dlp 调用与 Electron 下载两条链路 |

### P2

| 项 | 说明 |
|---|---|
| 每标签资源占用 | `app.getAppMetrics()` 与标签映射不稳定，需要按 webContents 维度采样 |
| 扩展兼容清单 | Electron 的 Chrome 扩展 API 子集有限，应展示「支持/不支持」而不是装完才发现 |
| 多窗口 / Profile | 工作与个人隔离；涉及 userData 分目录与会话迁移，改动面大 |

## 不做

- 密码管理与账号同步：成本高、信任门槛高，收益低于上面这些；
- 完整广告拦截：规则库维护与误杀成本不适合当前团队规模。
