# 浏览器功能强化：一条浏览闭环

> 目标版本 **0.163.25**（桌面端）。起点 0.163.24。
> 这份文档只回答三件事：现在缺什么、按什么顺序补、怎么验收。
>
> **状态（0.163.25）**：阶段 A–D 已实现；「书签栏」留下一个版本做（需要改页面视图布局，单独验证）。

## 1. 现状盘点（0.163.24）

| 环节 | 已有 | 缺口（被用户说「简陋」的部分） |
|---|---|---|
| 打开 | 标签、标签组、固定、休眠、静音、复制、拖动、会话恢复、最近关闭 | 「最近关闭」没有常驻入口，只能靠快捷键 |
| 导航 | 地址栏建议（搜索/直开/书签/历史）、搜索引擎切换、后退/前进/刷新、缩放 | 没有站点信息（安全状态/权限）；后退没有历史菜单 |
| 阅读 | 页内查找、缩放、深色、阅读模式、倍速、划词、截图 | **打印 / 另存为 PDF 缺失** |
| 保存 | 星标一键收藏、收藏到起始页 | 收藏不能改名/选文件夹；没有书签栏；没有导入导出 |
| 回访 | 历史/书签/下载/标签弹窗，可搜索、可清空 | 历史不分组、不能单条或按站点删除；下载不能批量暂停/继续、不能打开所在文件夹 |
| 清理 | 一键清除全部浏览数据 | 不能按范围清理（最近 1 小时 / 今天 / 全部） |

## 2. 目标流程：六步闭环

```
① 打开       ② 导航        ③ 阅读/操作     ④ 保存        ⑤ 回访        ⑥ 清理
启动/恢复  →  地址栏输入  →  查找/缩放/阅读  →  星标+文件夹  →  历史/书签/下载  →  按范围清除
新标签     ←  站点信息    ←  打印/存 PDF    ←  书签栏      ←  分组+搜索      ←  确认
```

规则：每一步都必须**能进来、能操作、能退出**——入口在地址栏/工具栏/快捷键里一致，
操作完留在原地，不弹不明所以的模态框。

## 3. 分阶段实施

### 阶段 A：数据层（migration 9） ✅

- `bookmarks` 增加 `folder` 列（`''` = 书签栏）；新增 `bookmark_folders(name, created_at)`。
- 历史：单条删除、按站点删除、按时间范围删除。
- 下载：批量暂停/继续、打开所在文件夹。

### 阶段 B：历史与下载（回访 + 清理） ✅

- 历史按「今天 / 昨天 / 更早」分组；单条删除、按站点删除；清理范围（1 小时 / 今天 / 全部）。
- 下载按日期分组，搜索，全部暂停/继续，打开所在文件夹。
- 快捷键 `Ctrl+H`（历史）、`Ctrl+J`（下载）。

### 阶段 C：书签体系（保存） ✅（书签栏 ⏭ 下一版）

- 星标改为「收藏弹窗」：可改名称、选文件夹；已收藏时打开编辑。
- 书签文件夹：新建/重命名/删除（删除只取消归类）。
- 书签管理：搜索、改名、移动、删除。
- 可选「书签栏」：显示在地址栏下方，文件夹以下拉菜单展开。

### 阶段 D：页面能力（阅读） ✅

- 打印（系统打印对话框）与「另存为 PDF」（文件对话框）。
- 站点信息气泡：当前站点、安全状态、权限入口、清除本站数据。

### 阶段 E：验证与发布 ✅

- 单测：数据层（folders/history 范围/批量下载）、站点信息选择器。
- 冒烟：补 1–2 条 E2E（历史分组删除、书签文件夹）。
- 文档：UI-GUIDE 浏览器章节、CHANGELOG、HANDOFF。
- 版本 0.163.25 → tag `v0.163.25` → 发布。

| 流程步骤 | 落地内容 | 入口 |

| ② 导航 | 地址栏左端站点信息：host、HTTPS/HTTP 状态、清除本站数据、站点权限设置 | 地址栏锁/地球图标 |

| ⑥ 清理 | 单站点清理（Cookie/存储）；历史按范围清理；全局清除保留 | 站点信息 / 历史页脚 |

未做（明确留给下一版）：书签栏（地址栏下方常驻条）、后退历史长按菜单。

## 4. 明确不做（这轮）

- 账号同步、密码管理、自动填充；
- 分屏浏览、独立书签同步服务；
- 重写标签管理或页面视图（现有 WebContentsView 架构不动）。

## 5. 验收标准

- 从任意网页出发，六步全部可达，且不需要记忆快捷键；
- 删除历史/书签/下载记录后列表立即更新，刷新后仍生效；
- `npm run check` 0 error / 0 warning；`npm run smoke` 22/22；
- 新功能有单测覆盖数据层，设置项有说明文字。
