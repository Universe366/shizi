# 插件—桌面端差异清单

> 更新：2026-10-31（桌面 0.162.26 / 插件 2.20.15）
> 用途：验收“插件端与桌面端细节是否一致”时逐项对照；不是像素级 UI 复刻。

## 字幕

| 能力 | 桌面端 | 插件端 | 状态 |
|---|---|---|---|
| 官方字幕抓取 | WBI 优先 + 身份校验 | 同 | 对齐 |
| 多语言轨切换 | 轨道选择器 | 语言下拉 | 功能对齐，呈现不同 |
| 手动选轨记忆 | 按视频记忆 | 按视频记忆 | 对齐 |
| 本地字幕导入 | SRT / VTT | SRT / VTT / JSON | 对齐 |
| 翻译 | 原文 / 译文 / 双语 | 同 | 对齐 |
| 断句 | 规则 + AI | 规则 | 规则对齐，AI 断句未移植 |
| 优化/校对 | AI 逐条 | AI 逐条 | 对齐 |
| 质检 | 质量面板 | 菜单内质量自检 | 功能对齐，入口不同 |
| 导出 | 6 格式 × 4 模板 | 同 | 对齐 |
| 语音转录 | 本地 Whisper + 在线 | 在线 + 桌面本地 Whisper | 对齐 |

## AI 与检索

- 两端共用 35 个 AI 平台目录：OpenAI 兼容、Anthropic、Gemini 原生、Azure OpenAI、Ollama、LM Studio 等；
- 检索支持 DeepSeek、Tavily、博查、Serper、智谱、秘塔、千帆、Brave、Exa、Firecrawl、Querit、Jina、SearXNG；
- 插件不保存桌面 DPAPI 加密的 Key；迁移或「只同步 Key」时由用户触发；
- Gemini 原生暂不参与 MCP 工具循环；
- 桌面新增视觉大模型 OCR、图片生成（OpenAI 兼容 / SD WebUI / ComfyUI）和更多 OpenAI 兼容 TTS 预设；
- 插件暂未加图片生成，OCR 仍以浏览器能力/桌面为主。

## 语音识别

- 插件在线：硅基流动、Groq、自定义 OpenAI 兼容；
- 桌面额外：本地 Whisper；
- 连接桌面时，插件可优先使用桌面本地 Whisper，不再误报未配置 Key。

## 已修问题

- 播放时工具栏每秒重建导致搜索框失焦、菜单/语言下拉关闭；
- 字幕导出/统计弹窗调用未定义 closeOverlay；
- 翻译不保留原文、无视图切换；
- 总结失败只弹 toast、无持久错误卡；
- 总结 [n] 纯文本、公式不渲染；
- MCP 工具无审批、直接执行；
- 桌面总结进度固定显示“桌面端生成”；
- 桌面本地 Whisper 可用时仍提示 ASR 未配置 Key；
- 保存设置重复弹提示。

## 明确暂缓

- 浏览器扩展运行本地 stdio MCP：平台限制；
- 插件与桌面逐像素一致的视觉布局；
- GitHub 仓库批量导入 Skills；
- AI 断句。
